# Customer Churn Prediction

## Problem Statement

Predict whether a customer will leave a service based on customer information and usage patterns.

## Objective

Build a machine learning classification model to predict customer churn.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
