# Customer Churn Prediction using Machine Learning

## Overview

This project uses machine learning techniques to predict whether a customer is likely to leave a service.

The goal is to analyze customer behaviour and build a classification model that can identify potential churn customers.

---

## Objective

- Analyze customer data
- Identify factors affecting customer churn
- Build and compare machine learning models
- Select the best-performing model

---

## Dataset

Dataset:
Telco Customer Churn Dataset

The dataset contains customer information such as:

- Demographics
- Services used
- Contract details
- Monthly charges
- Tenure
- Churn status

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## Machine Learning Models

Models implemented:

1. Logistic Regression
2. Decision Tree
3. Random Forest

---

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Hyperparameter Optimization

---

## Results

The models were compared using:

- Accuracy
- Precision
- Recall
- F1 Score

Random Forest with hyperparameter tuning was selected as the final model.
